Finance Dashboard
Your data lives in Google Sheets — this app reads and writes to it. Works across all your devices.

One-time setup

1
Go to console.cloud.google.com → New project → Enable Google Sheets API
2
Create an API Key and an OAuth 2.0 Client ID (web app type). Add your GitHub Pages URL to authorized origins.
3
Create a blank Google Sheet. Copy the ID from the URL (between /d/ and /edit).
4
Paste everything below and click Connect. Sheets and headers are created automatically.
Credentials saved in localStorage — never sent anywhere except Google.
