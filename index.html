Your data lives in Google Sheets. Works across all devices.

One-time setup

1
Go to console.cloud.google.com → New project → Enable Google Sheets API
2
Create an API Key and an OAuth 2.0 Client ID (web app). Add your GitHub Pages URL to authorized origins.
3
Create a blank Google Sheet and copy the ID from the URL.
4
Paste below and click Connect. Everything is created automatically.
Credentials saved in your browser only — never sent anywhere except Google.
